# STE-8 M1 UX closeout contract

Date: 2026-08-05

Status: implementation and verification complete; final owner visual acceptance pending

## Authority

This contract records the repository owner's final M1 simplification and supersedes
earlier STE-8 references to composer shortcuts, plugin/tool pickers, editable saved
Packets, and a permanently open Packet pane.

The retained visual authority is the accepted Rivet shell plus the owner-approved
Codex-style compact navigation and readable Markdown Packet treatment. No new visual
system is introduced.

## Final M1 behavior

- The composer contains only freeform text and send/stop controls.
- No plus menu, plugin picker, slash-skill picker, or selected-skill chip is visible.
- After a conversation has context, an in-thread Build Packet artifact action provides
  the explicit M1 path to create the first versioned fixture Packet.
- A saved Packet appears as an in-thread artifact card and opens into a secondary
  read-only Markdown document surface.
- The Packet renderer supports GFM and the bounded linear Mermaid form generated by
  the M1 fixture. If any Mermaid line is unsupported, the complete source block is
  shown instead of a partial or misleading diagram.
- Knowledge Base and Plugins are deferred surfaces under Settings. They inherit the
  active light/dark theme and do not claim connector execution.
- M2 owns canonical Packet contracts, manual editing/version management, verified
  identity, tenant isolation, and source ingestion. M3 owns planning intelligence.
